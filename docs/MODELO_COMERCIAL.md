# Modelo comercial PetID

## Producto 1: Kit PetID físico

- Credencial impresa y plastificada.
- Perfil digital.
- Código QR.
- Tag para collar.
- Despacho o retiro.

## Producto 2: PetID digital imprimible

- Diseño revisado.
- Perfil digital.
- QR definitivo.
- Archivo PDF o PNG de alta resolución.
- Impresión a cargo del cliente.

## Producto 3: Perfil PetID

- Perfil digital.
- QR.
- Modo extraviado.
- Posibilidad de comprar credencial o tag posteriormente.

## Flujo público recomendado

1. Cliente elige producto.
2. Completa datos y privacidad.
3. Sube fotografía.
4. Selecciona hasta tres estilos.
5. Realiza el pago.
6. PetID prepara propuestas.
7. Cliente aprueba una.
8. Se activa QR definitivo.
9. Se produce, despacha o habilita descarga.

## Ferias y atención presencial

El administrador usa el mismo editor, crea una solicitud presencial, confirma el pago y puede imprimir o dejar el pedido en producción.

## Capturas de pantalla

No es técnicamente posible impedirlas por completo. La defensa comercial es:

- Marca de agua.
- Vista de baja resolución.
- QR de muestra o QR oculto.
- No entregar reverso completo.
- Archivo final disponible solo después del pago.
- Perfil definitivo activado después de validar la orden.
